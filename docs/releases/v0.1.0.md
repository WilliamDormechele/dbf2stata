# dbf2stata v0.1.0

Initial public release of `dbf2stata`, a Python and Stata utility for batch conversion of DBF files to Stata `.dta` format.

## Highlights

- Batch-converts all `.dbf` files in a directory.
- Saves `.dta` files beside the source DBFs by default.
- Supports a separate output directory.
- Converts variable names to lowercase by default.
- Supports preserving DBF field-name case.
- Converts DBF date fields to Stata daily dates and datetime fields to Stata datetimes.
- Handles numeric, Decimal, logical, character, memo and supported binary-like fields.
- Protects existing `.dta` files from accidental overwrite unless replacement is explicitly requested.
- Provides both a Python command-line interface and a Stata command.
- Returns conversion summaries to Stata through `r()`.

## Validation

The release passed:

- 9 automated tests.
- Clean wheel installation testing.
- Python command-line conversion testing.
- Stata command testing.
- Interactive Stata file-selection testing.
- Validation on a legacy DBF collection containing 81 files and 382,566 records.

## Requirements

### Python

- Python 3.10 or newer
- `dbfread`
- `pandas`

### Stata

- Stata 16 or newer
- Python configured in Stata
- The `dbf2stata` Python package installed in Stata's Python environment
